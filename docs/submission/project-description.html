Beginora

An on-device AI assistant that helps people with ADHD start the task in front of them.

UnivaBio 2026 · Theme: AI for Human Health · Android app (React Native, Expo) · github.com/Chiboy06/Beginora

The problem

ADHD affects about 5% of children and 2.5% of adults worldwide (Polanczyk et al., 2007; Simon et al., 2009). Task initiation, starting a task you already intend to do, is a core everyday difficulty. Most planning apps need consistent manual logging, the very executive skill ADHD makes hard, and people drop them quickly. In much of Africa and Asia, ADHD is under-diagnosed and support is costly or absent; cloud AI tools also need steady data and send personal information to servers.

Our solution

Beginora turns a task you choose into one concrete first step you can start in about 30 seconds, then supports a calm five-minute focus session. A small language model runs entirely on the phone, so the core works offline, costs nothing per use, and keeps tasks private. Instead of waiting to be opened, it can notice when you seem stuck and reach out gently.

1. You type a task"I need to start my essay"
2. Safety checkCrisis or medical content gets a fixed, reviewed reply; no model call
3. On-device AI plansQwen3 via llama.cpp; output validated against a strict schema
4. One first step"Open the document and write one sentence"; rule-engine fallback if needed

Key features

  • First-step planner: on-device model with a validated plan contract and an offline rule-engine fallback.
  • Five-minute focus with done, snooze, "not the right step" and "smaller step", stored locally.
  • Gentle check-ins (opt-in): a background scan notices a stuck, untouched or overlong task and sends at most one calm note per task per day, never at night.
  • Phone-use patterns (opt-in): Android Usage access notices long scrolling or rapid app switching while a task waits. App names and times only, never content, never stored or sent.
  • Telegram for low-resource settings: /add, /next, /stuck, /done, or describe a task; replies only to your chat.
  • Chat assistant with tools: reminders, calendar review, and prefilled calls, texts and email you confirm and send yourself.

Health impact and rigor

  • Built for living with ADHD more easily: lowers the cost of starting rather than tracking.
  • Safety first: deterministic pre-check before any model call; prompt-injection attempts are blocked; model output is never shown unless it passes the schema.
  • Private by design: tasks stay on the device; every signal source is off until the user turns it on.
  • Calm language: no streaks, guilt, urgency or claims about the user.
  • Tested: 59 automated test suites (367 tests) cover the planner, safety rules, check-in rules, usage signals and the Telegram bot; fixes are checked by tests that fail on the old code.

Limits and next steps

A planning aid, not a medical device: it does not diagnose or treat ADHD. Background timing depends on each phone's battery rules. Next: a real-model evaluation set on desktop and phone, data export and delete-all, and a small consented pilot with students.

Beginora is a planning and focus aid, not medical care. It does not diagnose or treat ADHD and does not replace professional support.
